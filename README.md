## 🛠️ Ne Yapıyor Bu Şey?

`anlamsizlik_olcer.py` adlı bu olağanüstü yazılım:

1. Sizden varoluşunuzla ilgili bir cümle alır.
2. Karmaşık matematiksel formüller uygular (gerçekten karmaşık, gözünüzü kamaştırır).
3. Size **kesin, tartışılmaz, bilimsel** bir Anlamsızlık Skoru verir.
4. Hayatınızı değiştirebilecek felsefi bir yorum ekler.

Formül şöyledir (gizlidir ama açıklıyoruz çünkü çok güveniyoruz size):

```
(rastgele kaos × varoluşsal kriz) ÷ umut + 42
```

42'nin orada olması tesadüf değildir. Douglas Adams haklıydı.
